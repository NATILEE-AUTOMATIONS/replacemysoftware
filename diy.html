Set Up Supabase (Free Database)

Supabase is your database — where all your customer info, jobs, and notes live. It's like a spreadsheet in the cloud that your app talks to. The free tier gives you 500MB which is plenty to start.

supabase.com — Start Free

What to do: Sign up → Create a new project → Go to SQL Editor → Paste the prompt below into Cursor and it'll generate the SQL for you.

Prompt 1 — Database Setup
I'm building a roofing CRM using Supabase as my database. Write me the SQL to create these tables: 1. customers — id, name, phone, email, address, job_type, status, notes, created_at 2. jobs — id, customer_id, title, description, status, scheduled_date, crew, estimated_cost, actual_cost, created_at 3. materials — id, job_id, name, quantity, unit_price, total_price Include Row Level Security policies so anyone can read and write (we'll lock it down later with auth). Give me the SQL I can paste into Supabase SQL Editor.

Build Your App with Cursor + AI

Open Cursor, create a new folder called roofing-crm, and open it. Then open the AI chat (Cmd+L on Mac, Ctrl+L on Windows) and paste the prompt below. Cursor will generate your entire app — frontend, backend, everything.

Prompt 2 — Build the CRM
Build me a roofing CRM web app using Next.js, TypeScript, and Tailwind CSS. Here's what I need: DASHBOARD PAGE: - Stats cards at top: total customers, active jobs, revenue this month, jobs needing follow-up - Recent jobs table: customer name, job type, status, scheduled date, cost - Quick add button to create a new customer or job CUSTOMERS PAGE: - List of all customers with search by name/phone - Click a customer to see their full profile + job history - Add/edit customer form with: name, phone, email, address, job type, notes JOBS PAGE: - Kanban board with columns: Lead, Scheduled, In Progress, Completed, Invoiced - Drag jobs between columns to update status - Click a job to see details: customer info, crew assigned, materials, cost breakdown Connect it to my Supabase database. Here are my Supabase credentials: - URL: [paste your Supabase project URL] - Anon Key: [paste your Supabase anon key] Make it look clean and modern — dark theme, blue accents. Mobile responsive. Use Inter font.
💡 When Cursor asks for your Supabase URL and key, go to your Supabase dashboard → Settings → API. Copy the Project URL and anon key.
